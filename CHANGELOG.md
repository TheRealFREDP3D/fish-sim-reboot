# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2024

### Added
- Day/night cycle with smooth sky color transitions
- Four-season system (Spring, Summer, Autumn, Winter) with seasonal behaviors
- Recurrent neural networks for fish with temporal memory
- Layer-specific mutation rates for structured evolution
- Brain visualizer with animated neural activity display
- Cleaner fish with mutualistic cleaning behavior
- Predator fish with dash mechanics and blood effects
- Plant root systems that actively seek nutrients
- Soil grid with multiple soil types and nutrient diffusion
- Family cohesion system for parent-offspring bonding
- Bioluminescence at night for fish and plants
- Plankton diel vertical migration (surface at day, depth at night)

### Changed
- Refactored codebase into `src/fish_sim/` package structure
- Improved neural network architecture (30 inputs, 14+8 hidden, 12 outputs)
- Enhanced plant lifecycle with proper seasonal dormancy

### Fixed
- Predator hunting aggression improvements
- Plant seeding behavior in Spring
- Various stability and performance improvements
